# DYD 2026 — Offline Flutter App

A **static, fully offline** mobile companion app for **Diocese Youth Day 2026**. All content is bundled as local JSON assets — no API, no login, no internet required after install.

## App Flow

```
Splash → Home Dashboard
  ├── Diocesan Directory
  │     ├── The Diocese (History, Mission, Bishop's Message)
  │     └── Vicariates & Parishes → Parish Info & Delegates
  ├── Resources & Liturgy
  │     ├── Theme Song & Chants
  │     └── Prayers & Mass Guide
  ├── Emergency & Help
  │     ├── First Aid
  │     └── Emergency Contacts
  ├── Event Groupings
  │     ├── Assembly Points
  │     └── Groups / Clusters → Members
  └── Event Details
        ├── Host Parish (History, Priest, Coordinator, Leader messages)
        ├── History & Objective
        ├── Logo & Branding
        ├── Venue Map
        ├── Schedule
        ├── Speakers
        ├── Guidelines
        └── Committee Clusters (5 clusters, all sub-committees)
```

## Prerequisites

1. [Install Flutter](https://docs.flutter.dev/get-started/install) (SDK 3.2+)
2. Android Studio / Xcode for device emulators (optional)
3. A physical device or emulator for testing

## Setup

From this project folder:

```bash
# Generate Android/iOS platform folders (only needed once)
flutter create .

# Install dependencies
flutter pub get

# Run on connected device or emulator
flutter run
```

> **Note:** Platform folders (`android/`, `ios/`) are generated by `flutter create .` and are gitignored until you run that command locally.

## Updating Content (No Code Changes)

Edit the JSON files in `assets/data/`:

| File | Content |
|------|---------|
| `diocese.json` | Diocese history, mission, bishop's message |
| `vicariates.json` | Vicariates, parishes, delegates |
| `resources.json` | Theme song, chants, prayers, mass guide |
| `emergency.json` | First aid sections, emergency contacts |
| `groups.json` | Assembly points, youth groups, members |
| `event.json` | Full event info, schedule, speakers, committees |

### Images

Add these to `assets/images/`:

- `dyd_logo.png` — shown on splash screen and branding page
- `venue_map.png` — shown on the venue map page

After editing assets, rebuild the app:

```bash
flutter run
```

## Offline Design

- All data loaded via `rootBundle` from bundled JSON
- No network permissions required
- Content cached in memory on first read per session
- Safe for venues with poor connectivity

## Building for Release

```bash
# Android APK
flutter build apk --release

# Android App Bundle (Play Store)
flutter build appbundle --release

# iOS (macOS required)
flutter build ios --release
```

## Customization Tips

- **Theme colors:** edit `lib/core/theme/app_theme.dart`
- **App name:** edit `pubspec.yaml` and platform manifests after `flutter create .`
- **Committee structure:** already matches your 5-cluster layout in `event.json`
